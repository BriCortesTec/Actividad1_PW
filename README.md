# ACTIVIDAD 1 - Programación Web 7SD

Este repositorio continene los ejercicios prácticos como parte de la unidad 2.

## Descripción

Cada ejercicio explora un tema distinto trabajado durante los ejercicios en clase, integrando HTML,CSS y JavaScript según lo requerido en cada práctica.

## Contenido

El archivo `index.html` en la raíz funciona como menú de navegación, con enlaces a cada uno de los ejercicios. Las carpetas `css`, `js` e `img` contienen los recursos utilizados por los ejercicios.
